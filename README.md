# Lab 5: Spring Boot CRUD Application

A RESTful Actor Management web application built with Spring Boot, Apache Maven, and Lombok demonstrating full CRUD operations.

## Prerequisites

 Before running the application, ensure the following are installed:

- Java Development Kit (JDK): Version 17 or higher

- Apache Maven: 3.8+ (or use the included Maven Wrapper ./mvnw)

- Git

Verify your local environment:

<pre>
    java -version
    mvn -version
</pre>
